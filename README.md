# Charlie's Fish Finder

**Difficulty is a list, not a wall.** A single-file fish choosing & care app.

Use it here: **https://themikemonday.github.io/charlies-fish-finder/**

- Pick a fish and see its *actual* problems — each one typed as SETUP (solve once), HABIT (a routine), or RISK (watch for it, have a plan B) — instead of a "beginner/intermediate" label.
- Check every fish live against *your* tank: litres, heater temperature, shrimp, mystery snail.
- Judge each problem yourself: *I can own this / I'd need to learn / Dealbreaker.*
- Add your own fish (AI-research prompt + paste-back import, or a manual form) and grow your own dataset.
- My Tank tab: care routine with one-tap done logging and due-state colours, plus calendar (.ics) export so your device does the reminding.

All data stays on your device (browser localStorage) — nothing is uploaded anywhere. Use *Save my data* for backups.

Source of truth for this file lives in a private repo (`mai/tools/fish-care-app`); this repo exists to serve the app via GitHub Pages.
